# ANLI 可学习互补性：完整自动运行

2026-11-13。Ju 要求取消成功阶段之间的人工交接。本版取代此前“先回传 90 条预检包，再继续写正式入口”的操作安排。
内部仍按数据准备、预检、采集、拟合、冻结、评价的顺序执行，但通过检查后自动继续；只有实际错误或 allocation 余量不足才停止。
固定配置在 [anli_learnability_full_protocol.json](../configs/anli_learnability_full_protocol.json)，执行方法见 [运行手册](RUN_ANLI_LEARNABILITY_FULL_ZH.md)。

其他机器／队员的额外使用仍未确认；本版如实标注这一边界，不把它变成要求用户反复确认才能运行的门槛。
保留子集、round 标准化敏感性以及无法排除上游预训练暴露的解释沿用[审计记录](../records/anli-learnability-preparation-2026-11-12/input-audit.json)。

三个角色均对全部 22,437 条输入产生原始回答，共 **67,311 条正式预测**。旧 90 条开发输入的三模型预检自动先执行，

任何缺失或失败回答都会阻断对应采集，不能丢掉失败行后评价。

## 固定方法与评价

两个 gain router 使用同样的两枚正确性 logistic head，比较仅有前级信息与增加冻结文本表示的差别。
前级信息为三个类别概率、三个预测类别指示和 log1p 输入字符数；文本为固定 MiniLM 的 1,536 维字段对表示。
全部 token 按 254 个内容 token 分块，按内容数加权池化，不截断长字段；不搜索新 encoder，也不微调 LLM 或 encoder。

标准化只拟合 fitting 数据。优化器是固定 NumPy L-BFGS；每臂、每个后级和拟合量只比较 L2=1、0.1、0.01，
同一候选的两个 head 共用 L2；selection 的精确 10% 配额正确数相同时选强正则。模型保存所有候选、收敛信息与获选规则。
另在 selection 上选择正 gain、最多 10% 转交的部署阈值，允许零转交，平分选更少转交；应用于评价集时报告真实转交率。

主比较固定为 18k、Qwen9B 后级、eligible-dev 上 text gain 减 front gain 的准确率差。
离线配额严格为 floor(0.1*N)，按 ID 处理同分；2,000 次配对 premise bootstrap 每次重算配额，给出条件于已拟合模型的 95% 区间。
1 pp 仅是实用参考，不作等效界值。其他拟合量、StartLux9B 后级、train holdout 和 round 权重均为次要描述性结果。
保留直接模型、confidence 10%、固定随机与 hindsight oracle 对照。不把离线 top-k 写成在线预算或 SLO 结论。

拟合参数、两个评价池的全部路由分数和相关证据先写入不可变 freeze，再登记 gold access，随后才读取新评价标签和计算结果。
复跑评价不允许重新拟合；回传审计会从原始回答和冻结分数重新计算指标，而不是只比较文件哈希。

## 自动续跑与证据

128 请求为一个不可变采集分片；完整成功分片可跨 allocation 复用，部分未提交行保留为诊断。
正常余量不足产生 CHECKPOINT；新 allocation 上运行同一命令，自动识别新 Slurm job 并核实旧 job 已终止。
真正失败保留诊断，调查后才用 `--retry-failed`。不会凭历史 PID 发信号，当前子孙关系与内核 pidfd 决定可清理进程。

CPU 特征也分批保存，已验收批次在推理前跳过。CPU worker 有 allocation watchdog 和后代回收；进程停止报错也不会跳过清理。
完成后生成 REPORT.md、结果 JSON 和一个回传包。为避免超过上传大小限制，紧凑包省略模型、环境、原始源 ZIP 和特征矩阵字节，
保留特征哈希、完整输入、训练／评价标签、原始回答、拟合参数和冻结分数；矩阵仍保存在节点，可单独复制或用固定编码器重建。
紧凑包能重算评价结果；特征和拟合的完整数值复现还需保留矩阵或重新生成。

这是完整实验的软件交付，不是 GPU 实验已完成的声明。原生 Linux 自检、真实 vLLM 采集和正式结果仍由节点运行产生。
本轮不包含可选 encoder 微调或在线服务新实验；这些不影响当前主比较完成。
